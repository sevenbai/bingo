# 猜数字宾果游戏 (Number Guessing Bingo Game)

一个人类 vs AI 的猜数字对战游戏，基于经典的 Bulls and Cows 游戏规则。

## 游戏规则

1. **设置密码**：人类和AI分别设定4个0到9不重复的数字作为自己的密码（例如：2674）
2. **轮流猜测**：双方轮流猜测对方的密码
3. **获得反馈**：每次猜测后会得到 `?A?B` 格式的反馈
   - **A**：数字和位置都正确的个数
   - **B**：数字正确但位置不对的个数
   - 例如：密码是 `2674`，猜测 `1276` → 结果是 `1A2B`
     - 1A：数字6在正确位置
     - 2B：数字2和7存在但位置不对
4. **获胜条件**：先得到 `4A0B` 的一方获胜（完全猜中对方密码）

## 游戏特色

### AI策略
AI使用智能猜测策略：
- **约束满足算法**：根据历史猜测结果动态过滤可能的密码空间
- **启发式初始猜测**：第一次猜测使用 `0123` 以快速获得信息
- **最优选择**：从剩余可能的密码中选择最能区分答案的猜测

### 游戏体验
- 清晰的界面显示猜测历史
- 实时显示AI剩余可能的密码数量
- 回合制对战，公平竞争
- 支持随时退出游戏

## 技术实现

### 核心功能
- `validate_code()`: 验证密码格式是否合法
- `compare_codes()`: 比对密码和猜测，计算A和B
- `ai_make_guess()`: AI智能猜测算法
- `generate_all_possible_codes()`: 生成所有可能的密码组合（5040种）

### 算法复杂度
- 密码空间：10P4 = 5040 种可能的组合
- AI平均猜测次数：通常在 5-7 次之间
- 最坏情况：不超过 10 次猜测

## 策略提示

### 对人类玩家的建议
1. **第一次猜测**：使用 `0123` 或 `0145` 等分散的数字获取最多信息
2. **记录排除**：根据反馈排除不可能的数字和位置
3. **逻辑推理**：使用约束条件缩小可能的答案范围
4. **避免重复**：不要猜测与历史反馈矛盾的组合

### 示例推理
- 如果猜 `0123` 得到 `2A1B`，说明：
  - 有2个数字位置完全正确
  - 有1个数字存在但位置不对
  - 总共有3个数字是正确的
  - 剩下的6个数字（4-9）中只有1个可能在密码中
